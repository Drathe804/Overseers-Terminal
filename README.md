### SPECIAL

<p align="center">
  <img src="screenshots/special.jpg" width="900" alt="SPECIAL screen showing real-world attributes">
</p>

SPECIAL stats are connected to real-life systems. Strength, Endurance, and Agility are influenced by workout data from Swole Scroll. Intelligence is linked to GitHub activity. Charisma is currently connected to contacts.

### RADIO

<p align="center">
  <img src="screenshots/radio.jpg" width="900" alt="RADIO screen showing Android media control through Pip-Boy interface">
